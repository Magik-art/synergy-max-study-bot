# Учебный помощник в MAX

Компактный проект для самостоятельного разбора и демонстрации задания № 3.
Бот выбирает готовые ответы по ключевым словам и предлагает кнопки с темами.
Это личный учебный проект, не официальный бот университета.

В проекте четыре исходных файла:

- `bot.py` — распознавание вопроса, кнопки, подключение к MAX и запуск.
- `faq.json` — восемь тем, ответы, ключевые слова и служебные сообщения.
- `requirements.txt` — четыре используемые библиотеки с проверенными версиями.
- `README.md` — эта инструкция.

## Запуск в PyCharm

Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
Откройте полученную папку как отдельный проект. Выберите интерпретатор Python 3.11
или новее и установите библиотеки из `requirements.txt` в окружение проекта:

```bash
python -m pip install -r requirements.txt
```

Откройте `bot.py` и нажмите Run. Токен для обычного запуска не нужен.
Попробуйте «Что писать в отчёте?», «Договор и расписание», «Какая погода на Марсе?».
Команда `/exit` завершает диалог. В консоли выводится текст ответа; кнопки видны в MAX.

Из терминала бот запускается так:

```bash
python bot.py
```

## Как читать код

1. Посмотрите тему и её `rules` в `faq.json`.
2. `normalize()` и `tokens()` приводят вопрос к основам слов через NLTK.
3. `answer()` выбирает наибольший вес правила для каждой темы. Веса не складываются.
   При равенстве лучших весов бот предлагает уточнение, при слабом совпадении — меню.
4. `handle()` обрабатывает запуск, сообщение или кнопку MAX.
5. `message_body()` собирает кнопки, `post()` отправляет ответ через httpx.
6. `create_app()` принимает события через FastAPI, `main()` выбирает режим запуска.

Для отладки поставьте точку останова на `words = tokens(text)` внутри `answer()`.
Запустите Debug и следите за `words`, `scores` и `winners`.

В правилах `words` — обязательные слова, `weight` — вес, `context` — дополнительные
слова: при заданном контексте должно встретиться хотя бы одно из них.
Бот распознаёт формы слов, но не исправляет произвольные опечатки и не хранит контекст диалога.

## Подключение к MAX

```bash
python bot.py --max
```

Программа попросит токен MAX и секрет webhook скрытым вводом. Они не сохраняются
в исходниках. Секрет — от 24 до 256 латинских букв, цифр или дефисов.

Этот режим запускает локальный сервер на `127.0.0.1:8098`, принимающий POST
по пути `/study-bot/max/webhook`. Для реального MAX нужен опубликованный HTTPS-адрес,
настроенный на этот сервер, и подписка на `bot_started`, `message_created`,
`message_callback` с тем же секретом. Скрипт сам не меняет подписки и не публикует порт.
Одного локального запуска недостаточно, чтобы события MAX начали поступать.

В учебной версии ответ отправляется сразу при получении события. Здесь нет
постоянной очереди SQLite, защиты от повторной доставки и автоматических повторов
отправки. При сбое или повторном событии возможны потеря или дублирование ответа.
Эта учебная версия предназначена для разбора кода и демонстрации;
на сервере проекта работает отдельная версия с очередью событий.

## Библиотеки

- NLTK — основы русских слов, без загрузки корпусов и обучения модели.
- httpx — HTTPS-запросы к MAX.
- FastAPI — приём событий webhook.
- Uvicorn — запуск HTTP-сервера.

Для сдачи исходников достаточно этих четырёх файлов. Python-окружение и служебные
файлы PyCharm добавлять в архив не нужно. Результаты анализа и предложения по
улучшению относятся к отдельному отчёту по заданиям 4–5.

## Проверка учебной версии — 04.11.2026

Пройдены 30 автоматических проверок: распознавание, сообщения, кнопки,
отклонение неверного секрета и некорректных запросов, обработка ошибок API.
87 сравнений текста, темы и кнопок (в том числе 64 вопроса из отчёта) совпали
с большой версией. Это сохранение прежнего поведения, а не 100% точность распознавания.
Запросы MAX проверены на подставном HTTP-клиенте, без реальной отправки сообщений.
Локальное демо запущено в PyCharm и ответило на вопрос об отчёте.
